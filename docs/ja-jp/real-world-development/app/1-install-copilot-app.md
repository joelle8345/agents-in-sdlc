[**GitHub Copilot app**][about-copilot-app] は、エージェント主導の開発に使用するデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、継続的インテグレーション (CI) パイプラインをすぐに利用できます。すべての作業を自分で行うのではなく、それぞれ独立したワークスペースで複数のエージェントを並行して指示し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の内容を学びます。

- GitHub Copilot app をインストールしてサインインする。
- GitHub リポジトリからプロジェクトをアプリに追加する。
- テンプレートで用意されたバックログを含め、ワークスペースを確認する。
- クイックチャットを試してアプリ自体について学ぶ。

## シナリオ

チームは、増え続けるバックログに対応するために AI エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、またはいずれかの有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise では、管理者が **GitHub Copilot app** ポリシーを有効にしている必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加します。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストールが完了したらアプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地が設定された GitHub Enterprise Cloud を使用している場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリの選択を求められたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択を省略し、オンボーディングの後にプロジェクトを追加することもできます。
6. テーマの選択を求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリが表示されることを確認します。すでに表示されている場合は、再度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した owner とリポジトリ名を使います。
9. サイドバーにリポジトリが表示されていることを確認します。この画面では `tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にグループ化され、各リポジトリの下に個別のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの構成を確認します。サイドバーには、主に次の領域があります。

- **New** — ここから Copilot との新しいチャットセッションを開始できます。
- **Pull requests** — アプリにネイティブ統合された GitHub のプルリクエストを表示します。アプリを離れずに、プルリクエストの参照や絞り込み、CI の状態確認、レビューを行えます。
- **Issues** — GitHub issue を参照・絞り込みしたり、issue からセッションを開始したりできます。
- **Automations** — スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。やることリストや定期的なプロジェクト保守など、手間のかかる作業を任せるのに役立ちます。まとめでは次のステップとして紹介しますが、別のワークショップ演習ではありません。
- **Customize** — MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。Playwright MCP の設定に使います。
- **Chats** — 独自のブランチやワークスペースを必要としない、質問やブレインストーミング向けの簡単な会話です。最初のチャットを開始すると表示されます。表示されない場合は **Sessions** の横にある **+** を選択して最初のチャットを開始します。
- **Sessions** — リポジトリフォルダーとエージェントセッションをまとめます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリビューが開き、その下のセッションを選択すると会話に戻れます。各セッションは独立したワークスペースで実行されるため、変更が競合することなく複数のセッションを並行して実行できます。星評価を追加するときに、最初のセッションを開始します。

ワークショップを進めながら、ワークスペースを確認していきます。

> [!TIP]
> 操作方法がわからない場合や、何かが可能か知りたい場合は、Copilot に質問してください。操作方法を案内してくれます。

### 用意されたバックログを確認する

Tailspin Toys にも、テンプレートからリポジトリを作成したときに用意されたバックログがあります。現在のバックログを確認します。

1. サイドバーの **Sessions** で、個々のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。リポジトリの上部ナビゲーションで **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルを探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. issue を選択して詳細を読みます。各 issue からエージェントセッションを開始できます。簡単な最初の変更を完了した後、フィルタリングの issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は、Copilot app に追加したリポジトリの項目だけに自動的に絞り込まれます。ほかのリポジトリの作業項目を表示するには、そのリポジトリをアプリに追加します。

## クイックチャットを試す

アプリ自体について質問すると、アプリの使い方に慣れることができます。**quick chat** を使うと、ブランチや worktree を作成せずに質問やブレインストーミングができるため、セッションを必要としない、その場限りの短いやり取りに適しています。

1. サイドバーで **Chats** の横にある **+** を選択して新しいチャットを開きます。**Chats** が表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。チャットを開始すると **Chats** が表示されます。
2. アプリのセッションの仕組みについて質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションは独立した Git worktree で実行されるため、変更が競合することなく複数のエージェントを並行して実行できます。会話はいつでも続けられ、新しいチャットも開始できます。
